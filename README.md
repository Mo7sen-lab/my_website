# BiteSpot — موقع مطعم تجريبي

## تشغيل الموقع
1. فك ضغط ملف ZIP.
2. افتح مجلد `bitespot_restaurant`.
3. افتح `index.html` في المتصفح. ولتجربة أفضل أثناء التطوير، افتح المجلد في VS Code واستخدم إضافة Live Server.

## الملفات
- `index.html`: محتوى الموقع.
- `style.css`: الألوان والتصميم والتجاوب مع الموبايل.
- `script.js`: المنيو والبحث والتصنيفات وسلة الطلبات ورسائل واتساب والحجز.

## قبل نشر الموقع لعميل
1. افتح `script.js` وغيّر `WHATSAPP_NUMBER` إلى رقم واتساب المطعم بصيغة دولية، أرقام فقط، من غير `+` أو مسافات. مثال مصر: `201012345678`.
2. عدّل الاسم والوصف والأسعار ومواعيد العمل والعنوان ورقم الهاتف في `index.html`.
3. غيّر بيانات المنتجات والأسعار في مصفوفة `products` داخل `script.js`.
4. استبدل مربعات الصور التجريبية بصور أصلية تملك حق استخدامها. تعليقات HTML توضح أماكن الصور. بعد إضافة مجلد `images`، يمكنك استخدام عناصر مثل:
   `<img src="images/hero-meal.jpg" alt="وصف الوجبة">`
   وتعديل CSS الخاص بالصورة حتى تغطي المساحة المطلوبة.
5. استبدل آراء العملاء التجريبية بآراء حقيقية بموافقة أصحابها، أو احذف القسم.
6. اختبر الموقع على موبايل وكمبيوتر، وتأكد من جميع الروابط والأرقام والأسعار.

## حدود النسخة
- سلة الطلبات تعمل داخل المتصفح فقط، ولا تحفظ الطلبات في قاعدة بيانات.
- زر الطلب ينشئ رسالة واتساب؛ لا يوجد نظام دفع إلكتروني أو إدارة طلبات.
- نموذج الحجز يجهز رسالة واتساب، ولا يؤكد الحجز تلقائيًا.
- أرقام الأسعار والآراء المعروضة تجريبية. يجب مراجعتها مع صاحب المطعم قبل النشر.
- رابط Google Fonts يحتاج اتصال إنترنت. الموقع نفسه لا يحتاج مكتبات JavaScript خارجية.
